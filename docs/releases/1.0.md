# BeastDoubleWield 1.0

Initial public release with native offhand combat, progressive mining, configurable interaction rules, persistent player toggles, BeastLib integration, and bStats service ID **35021**.

- Added an optional invisible main-hand input placeholder, disabled by default. It requires Minecraft 1.14+, the matching client resource pack, `swing.air: true`, and `attack.allow-empty-hand: true`.
- Included five resource-pack examples and deterministic build/check scripts. Ordinary feathers retain their normal model. The hidden item enables input; it does not render an empty offhand fist.
- Audited legacy NMS signatures, including early block-sound fields, state-dependent sound getters, and empty-tool handling. The legacy implementation calls NMS through reflection.
- Expanded configuration comments and `/bdw status` diagnostics. New configurations use this repository's update feed.

Validation: **141 automated tests**, **17/17 native checks on Spigot 1.9.4**, and **37/37 native checks on Spigot 1.20.2**, with public BeastLib 1.7.0 in both release fixtures. All five pack examples passed structure and reproducibility checks.

Install the runtime [BeastLib dependency](https://modrinth.com/plugin/beastlib), then the plugin JAR. Restart the server after replacing a JAR; `/bdw reload` changes settings only. Resource packs are optional downloads and are never applied automatically.

Consult the [verification record](https://github.com/MrAxeTv/BeastDoubleWield/blob/main/docs/verification.md) for exact tested server builds, artifact hashes and remaining acceptance checks. A tested legacy build does not certify every version from 1.9 onward. Folia is not supported. Resource-pack visual rendering and Bedrock/Geyser behavior remain unverified.
