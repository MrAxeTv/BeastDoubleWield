# BeastDoubleWield 1.1 preview 1

Free development preview of BeastDoubleWield. The plugin JAR identifies itself as `1.1-SNAPSHOT`. Stable **1.0** and its update feed remain unchanged.

## Downloads and setup

Download `BeastDoubleWield-1.1-SNAPSHOT.jar`, install the runtime [BeastLib dependency](https://modrinth.com/plugin/beastlib), and restart your server after replacing the plugin JAR. `/bdw reload` applies settings and messages only.

The optional `BeastDoubleWield-firstperson-arm-26.3.zip` is for **Paper 26.3 with a native Minecraft Java 26.3 client**. Install and enable the ZIP manually in that client's resource-pack menu. One pack covers classic/slim skins, sleeves and both dominant hands. See the [pack catalog](../../examples/README.md) and [setup guide](../../examples/firstperson-arm/README.md) for configuration and compatibility. Offhand tools and weapons do not need the arm pack.

`SHA256SUMS.txt` identifies both downloads. Source, example pack assets, build scripts, tests and verification records are included in the tagged repository. Minecraft binaries, server worlds, logs and the provided BeastLib developer dependency are excluded.

## Changes since 1.0

- Optional player-skin offhand arm with corrected resting transforms and a vanilla shield-slot icon in inventory/HUD contexts. Real offhand items take priority.
- Removed main-hand input feather insertion; retained cleanup for old privately tagged carriers. Improved arm retention during hotbar changes, drops, pickups and inventory actions.
- Preserved main-hand axe stripping, scraping and unwaxing on valid targets. Tightened offhand mining input timing, corrected mining attributes and added the acting player's completion break sound.
- Added 50 selectable language files, PascalCase settings and transactional migration that preserves saved values and custom messages. The arm now has one switch: `OffhandArm.Enabled`.
- Added public pack examples, version guidance and reproducible build instructions.

## Verification and limits

The current JAR passed **328 tests**, with no failures, errors or skips; all 61 classes use Java 8 bytecode. All seven local JAR exports matched. The existing native GPU receipt matches the exact pack ZIP and all nine source assets: **241 checks at 1080p and 241 at 4K**, including 11 shader variants, arm/sleeve rendering and the GUI icon. Rebuilding preserved the ZIP bytes and timestamp.

This is an experimental prerelease. Live client pack-loading/gameplay acceptance, full world OIT composition and performance benchmarking remain incomplete. Earlier native server probes are tied to the older JARs named in their receipts, not this preview. Java 8 bytecode does not establish support for every server version; Folia remains unsupported. The arm is limited to the verified 26.3 path, and its entity shaders require an explicit merge with conflicting packs. See the [development record](../first-person-arm.md).
